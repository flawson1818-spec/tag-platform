# 📖 Livre CCXXVIII — La Pluie sur les Deux Champs

Deux cultivateurs travaillaient côte à côte.

Le premier labourait avec soin.

Le second remettait toujours son travail au lendemain.

Quand la pluie arriva, elle tomba sur les deux champs.

Quelques semaines plus tard, l'un était couvert d'épis.

L'autre demeurait presque vide.

Les enfants demandèrent :

> **« Pourquoi la même pluie n'a-t-elle pas produit le même résultat ? »**

Le Gardien répondit :

> **« La bénédiction visite tout le monde.
>
> Mais chacun prépare son cœur différemment pour la recevoir. »**
